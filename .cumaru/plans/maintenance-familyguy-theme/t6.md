# T6 — Build and install Family Guy

## What to do

Rebuild the path-backed Family Guy theme from `.assets/`, install that
single-theme build into the live font/cache/statusline locations, and verify the
installed state end to end.

## Context

The user explicitly requested installation. `stickers install --theme
familyguy` purges prior `ClaudeStatusLineStickers*` fonts and live cache outputs
before copying this single-theme build. It also backs up and updates
`~/.claude/settings.json`.

## Implementation

```bash
STICKERS_HOME="$PWD/.assets/work" python -m claude_statusline_stickers.stickers fetch --theme familyguy --force
STICKERS_HOME="$PWD/.assets/work" python -m claude_statusline_stickers.stickers build --theme familyguy
STICKERS_HOME="$PWD/.assets/work" python -m claude_statusline_stickers.stickers install --theme familyguy
```

Verify the installed font matches the fresh build, its cmap contains all six
`sprite.familyguy.*.full` glyphs in slot 9, the installed manifest maps the six
agent names, the statusline script exists, and `settings.json` points to it.
Smoke-test at least one Family Guy agent directory against the installed script.

## Done when

- [x] Fresh fetch and build pass with one theme, six agents, slot 9.
- [x] Install copies the new font and cache and wires the statusline command.
- [x] Installed font and manifest match the fresh Family Guy build.
- [x] A Family Guy agent directory resolves to its expected glyph.
- [x] The user is told to Cmd+Q the terminal so its font cache reloads.
