# T2 — Declare `codepointSlot` in every bundled theme.json

## What to do

Give each bundled theme a permanent slot number and surface it on `Theme`.

## Context

Slot 0 is reserved for the probe glyphs, which already occupy their own block at
the base of the layout. Themes start at slot 1. Slots are assigned in the order
the themes were added to the project, not alphabetically — the whole point is
that the number never tracks a sort order.

## Implementation

- Allocate: `pokemon` 1, `southpark` 2, `amongus` 3, `memes` 4, `powerrangers` 5,
  `cars` 6.
- Add `"codepointSlot": <n>` to each `themes/<name>/theme.json`.
- Add `codepoint_slot` to the `Sprite`-adjacent `Theme` dataclass and read it in
  `Theme.load()`. Missing field → `None`, so the build can raise a named error
  (T3) rather than the loader guessing a slot.

## Done when

- [x] All six bundled `theme.json` files carry a unique `codepointSlot`.
- [x] `Theme.load(<name>).codepoint_slot` returns the declared integer.
